# Popmask public website

Landing, support, privacy and terms for Popmask. Static HTML/CSS, self-hosted fonts, no analytics or third-party scripts. GitHub Pages serves `main` at the repository root.

Site: https://truizlop.github.io/popmask-site/

The iOS application source lives in a separate private repository. Only approved marketing captures, public artwork, font licenses and website source belong here.

The landing and support pages use the release design requested by the app owner, with a direct App Store download link to https://apps.apple.com/app/id6818458375. Website copy does not determine Apple’s actual review or release status.

The unmodified English App Store badge comes from https://developer.apple.com/assets/elements/badges/download-on-the-app-store.svg (downloaded October 4, 2026), reused from the app’s closing-card asset. Displayed at 180 CSS pixels wide with clear space; see https://developer.apple.com/app-store/marketing/guidelines/.

Fonts: Chewy (Apache 2.0), Patrick Hand (SIL OFL); license files are in assets. App artwork © 2026 Tomás Ruiz López.
