# Popmask public website

Landing, support, privacy and terms for Popmask. Static HTML/CSS, self-hosted fonts, no analytics or third-party scripts. GitHub Pages serves `main` at the repository root.

Site: https://truizlop.github.io/popmask-site/

The iOS application source lives in a separate private repository. Only approved marketing captures, public artwork, font licenses and website source belong here.

At public release, replace the coming-soon link and support availability paragraph with the verified App Store download at https://apps.apple.com/app/id6818458375. Do not advertise availability before Apple confirms it.
